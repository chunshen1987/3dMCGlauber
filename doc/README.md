# Investigation reports

Name each report `YYYY-MM-DD-short-topic.md`. Use the investigation date and a topic that makes the report easy to find.

## Suggested outline

1. **Question and scope** — what was investigated and which physics or software behavior was in scope.
2. **Setup and reproduction** — revision, local changes, commands, inputs, seeds, and relevant environment details.
3. **Results** — measurements or findings with units, uncertainties, and comparisons where applicable.
4. **Validation and limitations** — what was checked, what was inconclusive, and which assumptions affect interpretation.
